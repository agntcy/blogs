A coding agent under SHADI and Kyvvu

A replay of the four scenarios in Kyvvu/shadi-kyvvu-demo. The agent writes generated Python to a scratch file (write_code) and runs it (run_code). The JSON under each step is the record Kyvvu wrote to agent-out/kyvvu-trace.jsonl in a real run with kyvvu 1.1.0 and shadictl 0.2.0 on Linux; only the paths are shortened.

Kyvvu policy (demo-manifest.yaml)A step.exec needs a preceding step.gate whose decision is pass.
SHADI sandbox policy (sandbox.json)Read my-agent/, write only agent-out/, no network.
